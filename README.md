# Priors-Calibration-and-Cost-Probabilistic-Classifiers-for-Fraud-Detection-Under-Class-Imbalance
This project examines how class imbalance, resampling, probability calibration, and decision thresholds affect fraud-detection models. It uses the **ULB Credit Card Fraud Detection** dataset, obtained from [Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud?resource=download). The dataset was not included in the GitHub repository because its file size exceeds GitHub’s standard upload limit.

The study compares Gaussian Naive Bayes and logistic regression under four conditions: training on the original data, training with undersampling, undersampling with prior-probability correction, and raw-data training with Platt scaling. Results show that undersampling can leave ROC-AUC nearly unchanged while reducing AUC-PR and substantially distorting predicted fraud probabilities. For logistic regression, undersampling greatly worsened the Brier score, indicating poor probability calibration.

Prior correction improved logistic regression probability estimates but did not recover ranking performance. Naive Bayes required additional calibration because its assumptions may not fully match real fraud data. The findings show that resampling should not automatically be considered beneficial. Instead, fraud classifiers should account for the real class prior, calibrate predicted probabilities, and select classification thresholds based on the relative costs of false positives and false negatives.
